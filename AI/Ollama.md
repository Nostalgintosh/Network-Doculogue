# Ollama Installation

I have install Ollama to my node cluster with a Qwen local LM, I use a headless surver (Fedora Server Edition)
I what to have a local LM server in my computer cluster for simple help and experimation. 
in `local@dt-node-00` the command is `curl -fsSL https://ollama.com/install.sh | sh` then write you password then wait, once download simply right `ollama` then pick your LM model, wait, once download pick then use.
